This project explores the relationship between GDP per capita and suicide rates across countries using Python, pandas, Matplotlib, and scikit-learn.

## Project Overview

The project combines GDP data and global suicide-rate data, performs data cleaning and transformation, and conducts statistical analysis on 2020 country-level data.

## Main Tasks

- Cleaned and transformed raw JSON and CSV datasets
- Standardised country names for merging
- Converted monetary text values into numeric values
- Reshaped suicide-rate data from long to wide format
- Merged the datasets into a combined dataset of 176 countries
- Calculated Pearson and Spearman correlations
- Compared suicide-rate gender gaps between high- and low-GDP countries
- Used linear regression residuals to identify countries that deviated most from the expected GDP-suicide relationship
